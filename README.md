# novel-distill

对小说正文做「文风指纹蒸馏 + 设定文档抽取 + 去 AI 味检测」。

**零依赖、纯 JS、不联网、不调模型。** 一份 core 双入口：命令行 CLI（主入口）+ 可选 MCP 服务器（供 agent 调用）。不依赖 SillyTavern、不依赖任何宿主。

---

## 它解决什么

你手头有一大堆正文（自己写的、或者你想模仿的），想问三个问题：

1. **这本书的文风长什么样？** —— 句长节奏、标点习惯、对话占比、比喻密度、口头禅/高频词、书页口头语…… 全变成可量化的指纹。
2. **这个世界里有什么？** —— 人物 / 地点 / 组织 / 物件四类实体自动抽出并按提及频次排序，直接当作设定文档的骨架。
3. **这段文字有多少 AI 味？** —— 纯规则、可解释地定位 AI 写作痕迹（列表体、解释性括号、空泛形容词堆叠、说教连接词、平行排比……），给 0–100 分。不调模型、不联网、不引入新 AI 味。

三项都是「诊断 + 报告」，不做改写（改写留待后续版本）。

## 快速开始

不需要安装，有 Node 18+ 即可。

```bash
# 三项全出（默认）
node cli.js 你的小说.txt

# 只看文风指纹
node cli.js 你的小说.txt --style

# 只要设定档案
node cli.js 你的小说.txt --entities

# 只要 AI 味检测
node cli.js 你的小说.txt --deai

# 输出 Markdown 报告到文件
node cli.js 你的小说.txt -o report.md

# 输出结构化 JSON（供程序/agent 消费）
node cli.js 你的小说.txt --json -o report.json

# 限制分析长度（默认全部，大文件建议限制）
node cli.js 你的小说.txt --max-chars 300000
```

### 参数一览

| 参数 | 说明 |
| --- | --- |
| `--style` | 只做文风指纹 |
| `--entities` | 只做设定抽取 |
| `--deai` | 只做 AI 味检测 |
| `--json` | 输出结构化 JSON 而非 Markdown |
| `-o, --out <file>` | 结果写入文件（默认打印到终端） |
| `--max-chars <n>` | 最多分析多少字符 |
| `--quiet` | 不打印头部信息 |
| `-h, --help` | 帮助 |

不传 `--style/--entities/--deai` 时，三项全出。

## 编码自动探测

中文小说常见 GB18030 / Big5 / UTF-8。本工具会自动探测，无需事先转码。

探测思路：用非致命解码器解一遍，再按「CJK 字符占比 × 100 + 可打印字符占比 × 20 − 替换符比例 × 1000 − 控制字符比例 × 800」打分，取最高分。实测对 GB18030 文本置信度 93~97，与 Big5 区分明显。

会顺带做：去 BOM、`\r\n` 归一为 `\n`、HTML 实体还原（如 `&#183;` → `·`）、全角空格转半角。

## 产物长什么样

### 文风指纹（部分字段）

```
段落：共 40562 段，平均 38.4 字，中位 35，P90 72
句子：共 49025 句，平均 31.4 字，中位 28
短句（≤8字）占比 11.1%；长句（≥40字）占比 29.8%
标点密度：逗号 69.9/千字，句号 29.7/千字
对话占比 11.9%；比喻 24.4/万字
```

### 设定档案（示例）

```
人物：兰希尔(774)  安格斯  鲁尔纳  兰莉儿  兰西亚  ……
地点：西风王国(84)  苍翠帝国(80)  提西岚山脉(26)  ……
组织：斯家(212)  赫利斯家(109)  疾电骑士团  埃梅纳斯学院  ……
物件：白兰十字剑  翠月之弓  湖光之盾  超凡药剂  ……
```

### AI 味检测

```
AI 味评分：100/100  —— 高
  [!] 列表体出现 N 处
  [!] 解释性括号 N 处
  ……
```

分级：≥60 高 / ≥30 中 / ≥12 低 / 其余 很干净。

实测对照：AI 味大纲样本 = 100/100「高」，人类网文正文样本 = 11~13/100「很干净」，拉开近 90 分，判别边界清晰。

## 作为 MCP 服务器使用（可选）

`mcp-server.js` 是一个零依赖的 MCP stdio 服务器（协议 `2024-11-05`），把三项能力暴露给 Claude Desktop / Cursor 等支持 MCP 的 agent。

暴露的工具：

| 工具 | 说明 |
| --- | --- |
| `distill_style` | 文风指纹 |
| `distill_entities` | 设定抽取 |
| `distill_deai` | AI 味检测 |
| `distill_all` | 三项一次出 |

每个工具接受：`file`（必填）、`maxChars`（默认 500000）、`json`（是否返回结构化 JSON）。

在 MCP 客户端里配置（示例）：

```json
{
  "mcpServers": {
    "novel-distill": {
      "command": "node",
      "args": ["/absolute/path/to/novel-distill/mcp-server.js"]
    }
  }
}
```

> 不装 MCP 也完全不影响使用——CLI 才是主入口。

## 设计原则

- **零依赖**：只用 Node 内置模块，不需要 `npm install`。
- **不联网、不调模型**：所有分析本地完成，不存在「用 AI 去 AI 味」的悖论。
- **可解释**：每一分扣在哪都能说清楚，不是黑盒打分。
- **一份 core、双入口**：CLI 和 MCP 复用同一套分析器，行为一致。
